# 🌐 Удалённый доступ к роутерам RouteRich

## 📋 Обзор системы

RemoteRouteRich — это решение для безопасного удалённого управления роутерами и другими устройствами через защищённую VPN-сеть на базе технологии Tailscale. Система позволяет получить доступ к вашим устройствам из любой точки мира без необходимости настройки сложных VPN-соединений или открытия портов.

### 🎯 Преимущества системы

- **Безопасность**: Сквозное шифрование всех соединений
- **Простота**: Не требуется настройка портов и NAT
- **Масштабируемость**: Легко добавлять новые устройства
- **Кроссплатформенность**: Поддержка роутеров, ПК, смартфонов

## 🚀 Быстрый старт

### Шаг 1️⃣: Создание защищённой сети (Tailnet)

#### 1.1. Создание сети в один клик

1. Откройте браузер и перейдите по ссылке: [https://remote.routerich.ru/create-tailnet](https://remote.routerich.ru/create-tailnet)
2. Нажмите кнопку **"Создать сеть"** или **"Create Tailnet"**
   - Система автоматически создаст уникальное имя сети (например: `rraukx6ho`)
   - Вам НЕ нужно вводить никакие данные - всё происходит автоматически

> 💡 **Примечание**: Вы можете создать максимум 2 сети в день с одного IP-адреса

#### 1.2. Сохранение ключей доступа

> ⚠️ **КРИТИЧЕСКИ ВАЖНО!** 
> После создания сети вы получите ДВА ключа:
> 
> 1. **Device Auth Key** - для подключения устройств к сети
> 2. **Management Key** - для доступа к панели управления
> 
> **Эти ключи отображаются только один раз и не подлежат восстановлению!**
> 
> **Обязательно сохраните ОБА ключа в надёжном месте:**
> - Менеджер паролей (рекомендуется)
> - Защищённый текстовый файл
> - Зашифрованное хранилище

**Примеры ключей:**

**Device Auth Key** (для подключения устройств):
```
ts_authkey_aBcDeF1234567890aBcDeF1234567890
```

**Management Key** (для панели управления - 64 символа):
```
a1b2c3d4e5f6789012345678901234567890123456789012345678901234abcd
```

#### 1.3. Информация о созданной сети

После создания вы получите:
- **Имя сети**: например `rraukx6ho`
- **Домен сети**: `rraukx6ho.routerich.local`
- **Срок действия ключа**: 1 год с момента создания

## 📶 Настройка на роутере OpenWRT

### Шаг 2️⃣: Установка пакета Tailscale

#### 2.1. Вход в веб-интерфейс роутера

1. Откройте браузер и введите IP-адрес вашего роутера (обычно `192.168.1.1`)
2. Введите логин и пароль администратора

#### 2.2. Установка пакета с русской локализацией

1. В меню роутера перейдите: **Система** → **Пакеты**

2. Нажмите кнопку **"Обновить списки"** и дождитесь завершения

3. В поле **"Фильтр"** введите:
   ```
   luci-i18n-tailscale-ru
   ```

4. Найдите пакет в списке и нажмите **"Установить"**

5. Дождитесь завершения установки (обычно занимает 10-30 секунд)

### Шаг 3️⃣: Настройка подключения к серверу

#### 3.1. Переход в раздел Tailscale

После установки пакета:
1. Перейдите в раздел **VPN** → **Tailscale**

#### 3.2. Настройка сервера координации

1. В поле **"Адрес сервера"** введите:
   ```
   https://rc.routerich.ru/
   ```

2. Нажмите кнопку **"Сохранить и применить"**

3. Подождите 5-10 секунд для применения настроек

#### 3.3. Авторизация в сети

1. В разделе **"Аутентификация"** введите ваш **Device Auth Key** (начинается с `ts_authkey_`), полученный при создании сети

2. Нажмите **"Подключиться"**

3. Статус должен измениться на **"Подключено"** ✅

### 🔍 Проверка подключения

После успешного подключения:
- В панели управления [https://remote.routerich.ru/](https://remote.routerich.ru/) появится ваш роутер
- Роутер получит IP-адрес в диапазоне `100.64.x.x`
- Вы сможете подключаться к роутеру по этому IP из любой точки мира

## 📱 Настройка на Android

### Шаг 4️⃣: Установка приложения

#### 4.1. Скачивание APK-файла

Скачайте официальную версию приложения Tailscale:

📥 **[Скачать Tailscale v1.86.4 для Android](https://github.com/tailscale/tailscale-android/releases/download/1.86.4-t3149aad97-g4ef0c869b/tailscale-fdroid.apk)**

> 💡 **Совет**: Если ссылка выше не работает, перейдите на [страницу релизов](https://github.com/tailscale/tailscale-android/releases/tag/1.86.4-t3149aad97-g4ef0c869b) и скачайте файл `tailscale-fdroid.apk`

#### 4.2. Установка приложения

1. На смартфоне откройте **"Загрузки"** и найдите скачанный APK-файл
2. Нажмите на файл для начала установки
3. Если появится предупреждение о безопасности, разрешите установку из неизвестных источников
4. Следуйте инструкциям установщика

### Шаг 5️⃣: Настройка клиента

#### 5.1. Первый запуск

1. Откройте приложение **Tailscale**
2. При первом запуске приложение запросит разрешения — предоставьте все необходимые

#### 5.2. Подключение к серверу координации

1. Откройте меню (три точки в правом верхнем углу)
2. Выберите **"Настройки"** → **"Сервер координации"**
3. Введите адрес сервера:
   ```
   https://rc.routerich.ru/
   ```
4. Сохраните настройки

#### 5.3. Авторизация

1. Нажмите кнопку **"Войти"** или **"Sign in"**
2. Введите ваш **Device Auth Key** (начинается с `ts_authkey_`)
3. После успешной авторизации статус изменится на **"Connected"** ✅

### 📸 Пошаговые скриншоты

> 📌 **Примечание**: Скриншоты настройки Android-клиента доступны в папке:
> `/home/openwisp/ionscale/png/client andorid/`

## 🛠 Дополнительные возможности

### Управление устройствами

После подключения всех устройств вы можете:

- **Просматривать список устройств** в панели управления [https://remote.routerich.ru/](https://remote.routerich.ru/) используя ваш Management Key
- **Управлять доступом** между устройствами
- **Настраивать маршруты** для доступа к локальным сетям
- **Мониторить статус** подключений в реальном времени

> 📝 **Для входа в панель управления**: Используйте Management Key (64-символьный hex ключ), а НЕ Device Auth Key

### Доступ к локальной сети роутера

Для доступа к устройствам в локальной сети роутера:

1. В настройках Tailscale на роутере включите **"Subnet Routes"**
2. Укажите диапазон локальной сети (например, `192.168.1.0/24`)
3. В панели управления одобрите маршрут
4. Теперь вы можете обращаться к локальным устройствам через VPN

## ❓ Часто задаваемые вопросы

### Что делать, если потерян ключ доступа?

К сожалению, восстановить потерянные ключи невозможно. Вам потребуется:
1. Создать новую сеть (tailnet) на странице [https://remote.routerich.ru/create-tailnet](https://remote.routerich.ru/create-tailnet)
2. Получить новые ключи (Device Auth Key и Management Key)
3. Переподключить все устройства с новым Device Auth Key

> 💡 **Совет**: Вы можете создать до 2 сетей в день с одного IP-адреса

### Почему не подключается роутер?

Проверьте:
- ✅ Правильность введённого адреса сервера (`https://rc.routerich.ru/`)
- ✅ Корректность Device Auth Key (должен начинаться с `ts_authkey_`, без лишних пробелов)
- ✅ Наличие интернет-соединения на роутере
- ✅ Актуальность времени на роутере (должно быть синхронизировано)
- ✅ Не истёк ли срок действия ключа (1 год с момента создания)

### Как узнать IP-адрес устройства в сети Tailscale?

- В панели управления [https://remote.routerich.ru/](https://remote.routerich.ru/)
- В веб-интерфейсе роутера: **VPN** → **Tailscale** → **Статус**
- В приложении на смартфоне: раздел **"Устройства"**

### Безопасно ли использовать систему?

Да, система использует:
- 🔐 Сквозное шифрование WireGuard
- 🔑 Уникальные ключи для каждого устройства
- 🛡 Отсутствие открытых портов
- ✅ Проверенную технологию Tailscale
