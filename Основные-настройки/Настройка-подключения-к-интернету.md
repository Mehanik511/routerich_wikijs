## Навигация
В данной статье рассмотрим настройку различных типов подключений к интернету, включая **DHCP**, **L2TP**, **PPPoE** и **Static IP**.
Представлены пошаговые инструкции по созданию и конфигурации интерфейсов.

## Приступаем к настройке
### DHCP (Dynamic Host Configuration Protocol)
Откройте браузер и введите адрес: http://routerich.lan.
В разделе меню выберите **"Сеть → Интерфейсы"**.
Для быстрого перехода воспользуйтесь ссылкой: http://routerich.lan/cgi-bin/luci/admin/network/network

Перейдите на вкладку <kbd>Устройства</kbd>

Найдите устройство **wan** и нажмите <kbd>НАСТРОИТЬ...</kbd>.
В появившемся окне найдите в списке поле **MAC-адрес** и замените содержимое на требуемый MAC-адрес.

Нажмите <kbd>СОХРАНИТЬ</kbd>, затем <kbd>ПРИМЕНИТЬ</kbd> для записи настроек в устройство.

> Настройка **DHCP** завершена!
{.is-success}

### PPPoE (Point-to-Point Protocol over Ethernet)
Откройте браузер и введите адрес: http://routerich.lan.
В разделе меню выберите **"Сеть → Интерфейсы"**.
Для быстрого перехода воспользуйтесь ссылкой: http://routerich.lan/cgi-bin/luci/admin/network/network

Нажмите кнопку <kbd>ДОБАВИТЬ НОВЫЙ ИНТЕРФЕЙС...</kbd>

В появившемся окне, заполните поля:
- **Название:** введите имя интерфейса, например, ```PPPoE```
- **Протокол:** в выпадающем меню выберите **"PPPoE"**.
- **Устройство:** в выпадающем меню выберите **"Порт коммутатора: wan"**.

Нажмите <kbd>СОЗДАТЬ ИНТЕРФЕЙС</kbd> для завершения процесса создания интерфейса.

После создания интерфейса станут доступны дополнительные параметры конфигурации:
- **Имя пользователя PAP/CHAP:** укажите имя пользователя, предоставляемый вам от провайдера.
- **Пароль PAP/CHAP:** укажите пароль, предоставляемый вам от провайдера.
- **Концентратор доступа:** оставьте поле пустым для автоопределения.
- **Имя службы:** оставьте поле пустым для автоопределения.

Нажмите <kbd>СОХРАНИТЬ</kbd>, затем <kbd>ПРИМЕНИТЬ</kbd> для записи настроек в устройство.

> Для окончательного применения настроек может потребоваться перезагрузка устройства.
{.is-warning}

> Настройка **PPPoE** завершена!
{.is-success}

### Статический адрес (Static IP)
Откройте браузер и введите адрес: http://routerich.lan.
В разделе меню выберите **"Сеть → Интерфейсы"**.
Для быстрого перехода воспользуйтесь ссылкой: http://routerich.lan/cgi-bin/luci/admin/network/network

В списке интерфейсов найдите **WAN** и нажмите <kbd>ИЗМЕНИТЬ</kbd>.

В появившемся окне найдите поле **"Протокол"**, в выпадающем меню выберите **"Статический адрес"**.
Для изменения протокола нажмите на кнопку <kbd>ИЗМЕНИТЬ ПРОТОКОЛ</kbd>.

После изменения протокола, вам будут предоставлены 6 полей для конфигурации:

Настройка IPv4:
- **IPv4-адрес:** в данном поле укажите необходимый адрес, который вы получили от провайдера.
- **Маска сети IPv4:** маска подсети указывает, какая часть IP-адреса принадлежит сети.
- **IPv4-адрес шлюза:** IP-адрес шлюза, предоставляемый вам от провайдера.
- **Широковещательный IPv4-адрес:** генерируется автоматически на основе IP-адреса и маски подсети.

Настройка IPv6:
- **IPv6-адрес:** в это поле вводится статический IPv6-адрес.
- **IPv6-адрес шлюза:** если ваш провайдер поддерживает IPv6, вам будет предоставлен этот адрес.
- **IPv6 направление префикса:** префикс указывает, какая часть IP-адреса принадлежит сети.

Нажмите <kbd>СОХРАНИТЬ</kbd>, затем <kbd>ПРИМЕНИТЬ</kbd> для записи настроек в устройство.

---

**Пример полной конфигурации на примере локальной сети:**
| Параметр                            | Значение          |
|-------------------------------------|-------------------|
| **IPv4-адрес:**                     | `192.168.1.100`   |
| **Маска сети IPv4:**                | `255.255.255.0`   |
| **IPv4-адрес шлюза:**               | `192.168.1.1`     |
| **Широковещательный IPv4-адрес:**   | `192.168.1.255`   |
| **IPv6-адрес:**                     | `2001:db8::100`   |
| **IPv6-адрес шлюза:**               | `2001:db8::1`     |
| **IPv6 направление префикса:**      | `64`              |

> Настройка **статического адреса** завершена!
{.is-success}
